## 1. 개요 및 목적 (Executive Summary)

본 문서는 (주)드래곤알피에이(DragonRPA Co.)가 자체 연구·개발한 소프트웨어 자산(예: **매뉴얼 스튜디오**, RPA 도구 등)을 성공적으로 상용화하고, 시장 출시 과정에서 발생할 수 있는 **소스코드 유출, 불법 복제, 무단 도용, 크랙(Cracking), 법적 분쟁**으로부터 회사의 지식재산권(IP)을 완벽히 방어하기 위한 **실무 실행 절차 및 기술 보안 가이드**입니다.

소프트웨어 권리 보호는 단순한 '코드 암호화'만으로는 완성되지 않으며, **① 법적·제도적 보호 장치**, **② 기술적 저작권 보호(DRM)**, **③ 유통 및 라이선스 계약 체계**의 3중 방어선(Three-Line Defense)이 유기적으로 결합되어야 실효성을 발휘합니다.

```
       ┌────────────────────────────────────────────────────────┐
       │   (주)드래곤알피에이 3중 지식재산권(IP) 방어 아키텍처   │
       └────────────────────────────────────────────────────────┘
                                    │
       ┌────────────────────────────┼───────────────────────────┐
       ▼                            ▼                           ▼
[1] 법률적 제도적 보호        [2] 기술적 바이너리 보안     [3] 유통 및 계약 체계
- 한국저작권위원회 등록       - Nuitka C 네이티브 컴파일   - 표준 EULA (사용권 계약)
- 특허청 상표권 출원 (9/42류) - Ed25519 비대칭 머신락     - 1PC 1Key 노드락 발급
- 영업비밀 및 특허 검토       - 안티 롤백 & 안티 디버깅   - EV 코드 서명 (SmartScreen)
```

## 2. 법률적·제도적 권리 확보 절차 (Legal IP Protection)

### 2.1 한국저작권위원회 프로그램저작물 등록 (최우선 필수)
소프트웨어는 저작권법상 '컴퓨터프로그램저작물'로 창작과 동시에 저작권이 발생하지만, **한국저작권위원회에 정식 등록하지 않으면 침해 발생 시 법적 대응이 극도로 불리**합니다.

1. **등록 시 법적 효력**:
   - **법정손해배상 청구권 확보**: 침해자의 실제 손해액 입증이 어려워도 저작권법 제125조의2에 따라 프로그램당 최대 5,000만 원(영리 목적 고의 침해 시 최대 3배 징벌적 손해배상) 청구 가능.
   - **창작일 및 저작자 추정력 부여**: 등록증에 명시된 등록일/창작일에 해당 프로그램이 존재했음을 법원이 공적으로 인정(입증 책임이 상대방에게 전환).
   - **세제 혜택 및 기술 인증 우대**: 조세특례제한법상 연구개발비 세액공제 및 벤처기업 인증 시 공식 무형자산으로 평가.
2. **신청 절차 및 구비 서류**:
   - **신청 기관**: 한국저작권위원회 저작권등록시스템 ([cros.or.kr](https://www.cros.or.kr))
   - **제출물 1 (신청서 및 프로그램 개요서)**: 프로그램의 명칭, 용도, 주요 기능, 개발 환경(Python 3.11 / PyQt6 / Windows API 등) 기재.
   - **제출물 2 (프로그램 소스코드 복제물)**: 프로그램 소스코드의 처음 20장, 중간 20장, 마지막 20장(총 60장) 또는 전체 코드가 수록된 전자문서(PDF/ZIP).
   - **수수료**: 건당 약 60,000원 ~ 80,000원 (온라인 신청 기준).
   - **소요 기간**: 신청 후 약 3~4 영업일 이내 등록증 발급 완료.

## 3. 기술적 보호 및 DRM 보안 아키텍처 (Technical DRM)

파이썬 기반 소프트웨어의 가장 취약한 점은 `.pyc` 바이트코드가 일반적인 디컴파일러(`pycdc`, `uncompyle6`)에 의해 10초 만에 평문 코드로 복원된다는 점입니다. 상용화를 위해서는 이를 원천 차단하는 기술이 필수입니다.

### 3.1 배포 바이너리 무력화 방지 (C-트랜스파일)
단순 패커(`PyInstaller`) 사용을 금지하고, C 언어 트랜스파일러인 **Nuitka**를 단일 표준으로 채택합니다.

```
[Python 소스 (.py)] 
       │
       ▼ (Nuitka Transpiler)
[C++ / C 중간 코드 (.c / .cpp)]
       │
       ▼ (Microsoft Visual C++ 2022 최적화 컴파일러)
[기계어 네이티브 바이너리 (.exe / .pyd)]  <-- 디컴파일 불가 (완전한 어셈블리 기계어)
```

- **빌드 파라미터 표준**:
  ```powershell
  python -m nuitka `
      --standalone `
      --onefile `
      --enable-plugin=pyqt6 `
      --windows-icon-from-ico=assets/dragon_rpa.ico `
      --windows-company-name="DragonRPA Co." `
      --windows-product-name="Manual Studio" `
      --windows-file-version=1.2.0.0 `
      --windows-product-version=1.2.0.0 `
      --windows-file-description="DragonRPA Manual Studio" `
      --remove-output `
      --msvc=latest `
      manual_capture_studio.py
  ```
- **효과**: Python 바이트코드가 바이너리에 전혀 남지 않고 순수 x86_64 네이티브 기계어로 번역되어, IDA Pro나 Ghidra 같은 고급 디스어셈블러로도 로직 추출이 극히 어렵습니다.

---

### 3.2 비대칭 암호화 기반 하드웨어 바인딩 라이선스 (Node-Lock DRM)

고객이 라이선스 파일을 다른 PC로 복사하여 무단 사용하는 것을 방지하기 위해 **머신 고유 지문(HWID)**과 **비대칭 공개키 암호화(Ed25519 또는 RSA-2048)** 체계를 구축합니다.

```
[고객사 PC (Client)]                              [(주)드래곤알피에이 본사 (Issuer)]
       │                                                          │
       ├─ CPU Serial + Mainboard UUID + MAC                       │
       │  ==> SHA-256 해시 생성                                   │
       │                                                          │
       ├────────────── [머신 식별 코드 (HWID)] 전송 ─────────────>│
       │                                                          │
       │                                                          ├─ 고객 정보, 만료일, 모듈 권한 결합
       │                                                          ├─ [본사 개인키(Private Key)]로 전자서명
       │                                                          │
       │<──────────── [암호화 라이선스 키 (.lic)] 발급 ───────────┤
       │                                                          │
       ├─ 내장된 [공개키(Public Key)]로 무결성/서명 검증           │
       ├─ 로컬 HWID와 라이선스 HWID 일치 여부 대조                │
       └─ [PASS] 실행 승인 / [FAIL] 차단 및 종료                  │
```

1. **하드웨어 식별자(HWID) 추출 수식**:
   $$\text{HWID} = \text{SHA256}(\text{Motherboard\_UUID} \parallel \text{CPU\_ID} \parallel \text{Drive\_Serial})$$
2. **라이선스 토큰 페이로드 구조**:
   ```json
   {
     "customer_name": "고객사명",
     "customer_id": "CUST-2026-0042",
     "hwid": "7F8B2C9A-4E1D-9F02-AB3C-5566778899AA",
     "product": "ManualCaptureStudio",
     "edition": "Enterprise",
     "allowed_modules": ["F8_MODAL_CAPTURE", "PPT_SYNC", "DRAFT_STAMP"],
     "issued_at": "2026-09-11T00:00:00Z",
     "expires_at": "2027-09-10T23:59:59Z",
     "signature": "MEQCIE7x...[Ed25519 Signature by DragonRPA Private Key]..."
   }
   ```
3. **핵심 보안 원칙**:
   - **개인키(Private Key)**는 (주)드래곤알피에이 본사의 보안 라이선스 서버에만 보관하며, 절대 외부나 클라이언트 앱에 포함되지 않습니다.
   - 클라이언트 앱에는 오직 **공개키(Public Key)**만 컴파일 시 바이트 배열로 하드코딩됩니다. 공개키로는 서명 위조가 수학적으로 불가능합니다.

### 3.3 시간 조작(Anti-Rollback) 및 변조 탐지 체계

1. **시스템 시계 역행 방지 (현재 구현 완료된 방식 고도화)**:
   - 로컬 레지스트리 및 격리된 데이터 영역에 실행 시각을 암호화 기록.
   - 로컬 시간이 이전 기록보다 과거일 경우 즉시 실행 차단.
   - **온라인 환경 추가 검증**: 네트워크 연결 시 공인 타임 서버(pool.ntp.org 또는 드래곤알피에이 라이선스 서버 API)와 시간 대조.
2. **동적 디버깅 탐지 (Anti-Debugging)**:
   - 윈도우 `kernel32.dll`의 `IsDebuggerPresent()`, `CheckRemoteDebuggerPresent()`를 주기적 스레드에서 감시.
   - 올리디버거(OllyDbg), x64dbg, Cheat Engine 등이 감지되면 에러 메시지 없이 조용히 종료(Silent Exit) 또는 라이선스 무효화 처리.

### 3.4 Windows Code Signing (코드 서명 인증서) 획득

상용 프로그램을 고객사에 배포할 때 가장 큰 장벽은 윈도우의 **SmartScreen ("인식할 수 없는 앱입니다", "PC 보호") 푸른색 경고창**입니다.

1. **인증서 종류**:
   - **EV (Extended Validation) 코드 서명 인증서**: 발급 즉시 마이크로소프트 SmartScreen 평판(Reputation)을 획득하여 경고창이 일절 뜨지 않음. (물리 보안 토큰(HSM USB) 또는 클라우드 HSM 발급 필요).
   - **OV (Organization Validation) 코드 서명 인증서**: 기업 실존 확인 후 발급. 초기에는 다운로드 수와 평판이 쌓일 때까지 일시적 경고가 뜰 수 있음.
2. **발급 기관(CA)**:
   - Sectigo, DigiCert, GlobalSign (국내 공인 대행사: 한국전자인증, 애니서트 등)
   - 연간 비용: 약 30만 원 ~ 60만 원 선.
3. **서명 집행**:
   ```powershell
   signtool sign /tr http://timestamp.digicert.com /td sha256 /fd sha256 /a "ManualCaptureStudio.exe"
   ```
   - 디지털 서명이 완료되면 속성 창에 `(주)드래곤알피에이`의 공인 인증 마크가 표시되어 기업 고객의 보안 검수를 손쉽게 통과할 수 있습니다.
