## 🖥️ 3. 상단 메뉴바 구성 (Menu Bar)

### ① 파일 (File - Alt+F)
- **📸 고정 캡처 (F9)**: 설정된 고정 좌표 영역을 즉시 캡처.
- **📐 영역 지정 캡처 (Shift+F9)**: 새 영역을 마우스 드래그로 설정하여 캡처.
- **🪟 부분 추가 캡처 (F8)**: 메인 화면 위로 뜬 모달 팝업을 부분 캡처하여 오버레이 객체로 추가.
- **📂 프로젝트 열기... (Ctrl+O)**: 작업 이력이 보존된 `.mcs.json` 프로젝트 불러오기.
- **💾 프로젝트 저장 (Ctrl+S)**: 개별 주석 객체와 원본 이미지를 분리 저장.
- **🖼 외부 이미지 열기...**: 기존 보유 중인 PNG/JPG 스크린샷 파일을 캔버스로 불러오기.
- **🚀 PPT 슬라이드 생성 (F10)**: 현재 완성본을 파워포인트 슬라이드로 다이렉트 전송.
- **❌ 종료 (Alt+F4)**: 프로그램 종료.

### ② 편집 (Edit - Alt+E)
- **↩ 실행 취소 (Ctrl+Z)**: 직전 편집 작업 롤백.
- **📋 클립보드 복사**: 캔버스 완성 합성 이미지를 Windows 클립보드로 복사 (카톡/노션/보고서 붙여넣기 가능).
- **🗑 전체 삭제**: 캔버스의 모든 주석 개체를 일괄 제거하고 원본 캡처만 남김.
- **🔢 PPT Step 번호 자동 재정렬**: 열려 있는 파워포인트 문서 전체를 스캔하여 슬라이드별 `Step N` 번호를 1부터 오름차순으로 일괄 재부여.

### ③ 도구 (Tools - Alt+T)
- **👆 선택 모드**: 배치된 개체를 클릭하여 이동, 크기 조절, 삭제.
- **① 번호 스탬프**: 클릭 시 `①`, `②`, `③` 순차 증가 원형 번호 스탬프 삽입.
- **①➔ 스탬프 화살표**: 번호 스탬프와 지시 화살표가 일체화된 원터치 가이드 객체 삽입.
- **↳ 직각 화살표**: 메뉴 이동 경로를 L자형으로 깔끔하게 꺾어 가리키는 화살표 삽입.
- **↗ 직선 화살표**: 대상 버튼이나 입력창을 사선으로 직관 지시하는 화살표 삽입.
- **🔲 사각 박스**: 강조 영역을 빨간색 테두리 또는 반투명 하이라이트로 감싸기.
- **🌫 모자이크 블러**: 고객명, 전화번호, 단가, 계좌번호 등 민감 정보를 비파괴 격자 모자이크로 가리기.
- **📑 Draft 스탬프**: 화면 중앙에 60도 회전된 큼직한 'DRAFT' 워터마크를 원클릭 주입.
- **💬 설명 말풍선**: 지시선 꼬리가 달린 설명 텍스트 상자 삽입.
- **🔤 텍스트 라벨**: 캔버스 빈 곳에 자유로운 텍스트 문구 기재.
- **⌨ 단축키 뱃지**: `Ctrl + C`, `Enter` 등 키보드 키캡 모양 3D 뱃지 삽입.

### ④ 설정 (Settings - Alt+S)
- **⚙ 환경 설정...**: 고정 캡처 좌표, 단축키 변경, 파워포인트 여백(Left/Top/배율) 및 테마 색상 설정.

### ⑤ 정보 (About - Alt+A)
- 회사 공식 CI 로고, 프로그램 버전, 기간 한정 평가판 유효기간 안내 및 고객 지원 이메일(`77.victor.lee@gmail.com`) 복사 기능 제공.

## 🎨 4. 리본 툴바 및 기능 버튼 상세 (Ribbon Panels)

### [탭 1: 도구 (Tools)]

#### 1. 캡처 그룹
- **`[📸 고정 캡처 (F9)]`**: 지정된 고정 박스 영역을 즉시 캡처하여 스튜디오 캔버스에 로드.
- **`[📐 영역 지정 (Shift+F9)]`**: 전체 화면 드래그 오버레이를 열어 캡처 영역을 지정.
- **`[🪟 부분 추가 (F8)]`**: 현재 캡처본을 유지한 채, 팝업창이나 모달을 추가로 오려내어 이동 가능한 스티커 이미지로 주입.

#### 2. 프로젝트 그룹
- **`[📂 프로젝트 열기]`**: `.mcs.json` 파일 열기.
- **`[💾 프로젝트 저장]`**: 작업본 영구 보존.
- **`[🖼 이미지 열기]`**: 외부 스크린샷 로드.
- **`[📋 클립보드 복사]`**: 주석이 합성된 이미지를 즉시 클립보드 복사.

#### 3. 선택·편집 그룹
- **`[👆 선택]`**: 마우스로 주석 객체 클릭 선택, 드래그 이동, 핸들 리사이징.
- **`[↩ 실행 취소]`**: 직전 작업 롤백.
- **`[🗑 전체 삭제]`**: 캔버스 주석 일괄 초기화.

#### 4. 단계·흐름 그룹 (핵심 추천)
- **`[① 번호 스탬프]`**: 클릭할 때마다 1씩 증가하는 원형 번호 배치. 중간 번호 삭제 시 뒷번호가 자동으로 1씩 당겨짐.
- **`[①➔ 스탬프 화살표]`**: 번호 원형과 화살표 머리가 하나로 합쳐진 지시선.
- **`[↳ 직각 화살표]`**: 시작점과 끝점 사이를 L자 직각으로 자동 라우팅하는 화살표.
- **`[↗ 직선 화살표]`**: 시작점에서 끝점으로 곧게 뻗는 정밀 화살표.

#### 5. 강조·보안 그룹
- **`[🔲 사각 박스]`**: 강조하고 싶은 입력 필드나 버튼 영역을 둘러싸는 사각형.
- **`[🌫 모자이크 블러]`**: 화면 내 고객 개인정보나 결제금액을 흐리게 가려주는 보안 블러.
- **`[📑 Draft 스탬프]`**: 검토용/초안 표시를 위한 대형 반투명 워터마크 스탬프.

#### 6. 텍스트·단축키 그룹
- **`[💬 설명 말풍선]`**: 지시선 꼬리가 달린 텍스트 상자. 말풍선 꼬리를 잡고 원하는 버튼으로 연결 가능.
- **`[🔤 텍스트 라벨]`**: 반투명 배경의 명확한 설명 라벨.
- **`[⌨ 단축키 뱃지]`**: 실제 키보드 키캡처럼 입체감 있는 단축키 버튼 객체.

#### 7. PPT 출력 그룹
- **`[🚀 슬라이드 생성 (F10)]`**: 열려 있는 파워포인트의 마지막 슬라이드 뒤에 새 슬라이드를 만들고, 완성 이미지를 16:9 슬라이드에 최적 맞춤으로 삽입.
- **`[📐 슬라이드 맞춤]`**: 슬라이드 여백을 계산하여 이미지 배율을 자동 맞춤.
- **`[☑ 제목 상자]`**: 슬라이드 상단에 `Step N. [단계명 입력]` 텍스트 박스 자동 생성 여부 토글.
- **`[🔢 Step 재정렬]`**: 열린 PPT 전체 슬라이드를 검사하여 Step 번호(Step 1, Step 2...)를 처음부터 순차 일괄 재부여.

## 📋 5. 4단계 실무 매뉴얼 제작 워크플로우

1. **1단계: 고정 캡처 (`Shift+F9` ➔ `F9`)**
   - 최초 1회 `Shift+F9`로 업무 프로그램 화면 영역을 지정하면, 이후부터는 `F9`만 누르면 같은 영역이 0.1초 만에 캡처됩니다.
2. **2단계: 직관 주석 배치 (`①`, `↳`, `🔲`, `🌫`)**
   - 클릭 한 번으로 `① 번호 스탬프`를 찍고, 메뉴 이동은 `↳ 직각 화살표`, 민감 정보는 `🌫 모자이크 블러`로 드래그하여 가립니다.
3. **3단계: 설명 말풍선 & 단축키 삽입**
   - 상세 안내가 필요한 버튼에 `💬 설명 말풍선` 꼬리를 연결하고, `⌨ 단축키 뱃지`(`Ctrl+S`)를 놓습니다.
4. **4단계: 원클릭 PPT 생성 (`F10`)**
   - `F10`을 누르면 실행 중인 파워포인트에 즉시 슬라이드가 1장 추가되며, 제목 상자(`Step 1.`)와 최적 배율 이미지가 자동 안착됩니다.
